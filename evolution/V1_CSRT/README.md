# V1 — CSRT Manual Tracking

## Overview

V1 represents the earliest stage of Project Silent Reaper.

This version used OpenCV's CSRT tracker to manually select and track a target through a video stream.

## Features

* Manual target selection
* CSRT object tracking
* Real-time visualization
* Basic tracking persistence

## Limitations

* No automatic detection
* No multi-object tracking
* No re-identification
* Tracking lost under heavy occlusion

## Significance

This version served as the foundation for all future development stages and established the basic tracking pipeline used throughout the project.
